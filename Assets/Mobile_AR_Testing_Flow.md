# 手机AR测试完整流程

## 概述

这是一个基于EasyAR稀疏空间地图的AR编辑器测试系统，专门为手机操作设计。系统包含两个测试脚本：
- **TestMapFunctions.cs** - 键盘输入测试（适用于Unity Remote调试）
- **MobileTestUI.cs** - 手机触摸UI测试（适用于真实设备测试）

## 系统架构

### 核心组件
```
EasyARSpatialMapEditorManager (管理器)
├── TestMapFunctions (键盘测试)
└── MobileTestUI (手机UI测试)
```

### 数据流
```
用户输入 → 测试脚本 → 编辑器管理器 → EasyAR组件 → AR效果
```

## 完整测试流程

### 阶段1：环境准备

#### 1.1 Unity项目设置
1. **导入EasyAR插件**
   - 确保EasyAR Sense Unity Plugin已正确导入
   - 检查License Key配置

2. **配置Android设置**
   ```
   File > Build Settings > Player Settings > Android
   - Scripting Backend: IL2CPP
   - Target Architectures: ARM64
   - Minimum API Level: 24
   ```

3. **添加测试脚本**
   - 将`TestMapFunctions.cs`添加到场景
   - 将`MobileTestUI.cs`添加到场景
   - 确保`EasyARSpatialMapEditorManager`在场景中

#### 1.2 设备准备
1. **Android设备**
   - 启用开发者选项
   - 启用USB调试
   - 安装Unity Remote（用于调试）

2. **连接方式**
   - USB连接（推荐）
   - WiFi连接（可选）

### 阶段2：基础功能测试

#### 2.1 地图管理测试

**使用键盘测试（Unity Remote）**
```
按键C → 开始创建地图
按键S → 保存地图
按键L → 加载地图
按键X → 清除地图
按键P → 切换点云显示
```

**使用手机UI测试**
```
主面板 → 地图控制 → 创建地图
主面板 → 地图控制 → 保存地图
主面板 → 地图控制 → 加载地图
主面板 → 地图控制 → 清除地图
主面板 → 地图控制 → 切换点云
```

#### 2.2 编辑模式测试

**使用键盘测试**
```
按键E → 进入编辑模式
按键Q → 退出编辑模式
按键I → 显示详细信息
```

**使用手机UI测试**
```
主面板 → 编辑模式 → 进入编辑模式
主面板 → 编辑模式 → 退出编辑模式
主面板 → 信息 → 查看详细信息
```

### 阶段3：对象操作测试

#### 3.1 对象放置测试

**使用手机UI测试**
```
主面板 → 编辑模式 → 放置对象 → 选择对象类型
- Cube（立方体）

```

### 阶段4：高级功能测试

#### 4.1 自动测试
```
主面板 → 自动测试 → 开启/关闭自动测试
```

自动测试流程：
1. 开始创建地图
2. 等待地图构建完成
3. 保存地图
4. 加载地图
5. 进入编辑模式
6. 测试完成

#### 4.2 碰撞检测测试
```
TestMapFunctions.TestHitDetection(screenPosition)
TestMapFunctions.TestObjectPlacement(prefab, screenPosition)
```

## 手机操作详细指南

### 主界面操作

#### 1. 主面板
- **地图控制按钮** - 进入地图管理功能
- **编辑模式按钮** - 进入对象编辑功能
- **信息按钮** - 查看系统状态信息
- **自动测试按钮** - 开启/关闭自动测试

#### 2. 地图控制面板
- **创建地图** - 开始构建新的空间地图
- **保存地图** - 保存当前地图到本地
- **加载地图** - 加载已保存的地图
- **清除地图** - 清除当前地图数据
- **切换点云** - 显示/隐藏点云数据

#### 3. 编辑模式面板
- **进入编辑模式** - 激活对象编辑功能
- **退出编辑模式** - 退出对象编辑功能
- **放置对象** - 打开对象选择面板
- **移除对象** - 删除最后放置的对象

#### 4. 信息面板
- **状态信息** - 显示当前系统状态
- **地图信息** - 显示可用地图列表
- **对象信息** - 显示已放置对象信息

### 对象操作流程

#### 1. 放置对象
```
1. 点击"编辑模式"按钮
2. 点击"进入编辑模式"按钮
3. 点击"放置对象"按钮
4. 在对象面板中选择对象类型
5. 对象会自动放置在屏幕中心位置
```

#### 2. 移除对象
```
1. 点击"编辑模式"按钮
2. 点击"移除对象"按钮
3. 最后一个放置的对象会被删除
```

## 常见问题解决

### 1. 地图构建失败
**症状**：点击创建地图后无反应
**解决**：
- 检查设备摄像头权限
- 确保环境光线充足
- 检查EasyAR License配置

### 2. 对象放置失败
**症状**：选择对象后无法放置
**解决**：
- 确保已进入编辑模式
- 检查地图是否已本地化
- 确保屏幕中心有可放置区域

### 3. UI无响应
**症状**：按钮点击无反应
**解决**：
- 检查UI组件是否正确配置
- 确保脚本已正确添加到场景
- 检查Console错误信息

### 4. 性能问题
**症状**：操作卡顿或延迟
**解决**：
- 降低画面质量设置
- 关闭不必要的功能
- 检查设备性能
